IMPORTANT LIMITATION:
This is NOT a completed native feature migration. The current native app is Phase 1 only.
- Native FIT import has not been validated against a real Garmin dive FIT file on iPhone.
- Native UDDF has parity gaps: duplicate timestamps are not collapsed; temperature parsing currently only accepts Kelvin-like values (200...350), while the web importer preserves already-Celsius values.
- The UI only exposes a single time offset; two-anchor sync is not wired to the UI.
- The preview only offers whole-HUD drag, opacity, and scale; independent widget visibility/editing, rotation snapping, alignment guides, and identity controls are not ported.
- DiveVideoExporter.swift is not called by ContentView. It is a draft, not a user-accessible export workflow; it does not enforce/verify the V8.18 4K export requirements or provide the complete save flow.
- XcodeGen generation, Xcode/iOS build, Garmin Swift Package resolution, real-device import, and video export were not run in this Linux environment.

DO NOT describe this package as feature-complete until those gaps are fixed and tested.
To preserve the website, keep index.html, fit-import.js and sw.js in the GitHub Pages publishing root without editing or renaming them.
