Upload guidance:
1. Extract this ZIP.
2. Upload the CONTENTS of the DepthStudio-iOS folder to the ROOT of the DepthStudio-iOS GitHub repository (main branch), replacing same-named files.
3. Do NOT upload this package to the separate web DepthStudio repository.
4. Commit the changes.
5. Run the workflow named: Depth Studio · V8.18 Native Parity + Fullscreen Launch + AltStore IPA.
6. Download only build/DepthStudio.ipa from Codemagic artifacts.

Signing note:
The IPA is intentionally unsigned at build time. Import it into AltStore, which signs it with the Apple ID configured in AltStore. It is not an App Store distribution IPA.

Privacy note:
The connected GitHub service previously reported this repository as Public. Before upload, verify Settings > General > Danger Zone > Change repository visibility and set it to Private if you want the source private.
